# อักษราบุ๊ค — เว็บไซต์อ่านนิยายออนไลน์ (พร้อมระบบหลังบ้าน useradmin)

เว็บไซต์อ่านนิยายออนไลน์ที่ออกแบบให้ผู้อ่านทั่วไปเปิดเว็บแล้วเลือกอ่านได้ทันทีโดย **ไม่ต้องล็อกอิน** และมีระบบหลังบ้านสำหรับ `useradmin` เพื่อลงนิยาย เขียนตอนใหม่ จัดการหมวดหมู่ และแก้ไของค์ประกอบต่างๆ ภายในเว็บไซต์ได้อย่างอิสระ

## จุดเด่นของระบบ

### ฝั่งผู้อ่าน (ไม่ต้องล็อกอิน)
- เปิดหน้าเว็บแล้วเลือกอ่านนิยายได้ทันที
- ค้นหานิยายจากชื่อเรื่อง ผู้แต่ง เรื่องย่อ หรือแท็ก และกรองตามหมวดหมู่/สถานะ/ยอดอ่าน
- หน้าอ่านนิยายสบายตา ปรับธีมได้ 3 แบบ (**สว่าง / ถนอมสายตา / มืด**), ปรับขนาดตัวอักษร, เลือกฟอนต์มีหัว/ไม่มีหัว และมีแถบความคืบหน้าการอ่าน
- ระบบ **อ่านต่อจากที่ค้างไว้** และ **ชั้นหนังสือ (Bookmark)** บันทึกอัตโนมัติในเบราว์เซอร์โดยไม่ต้องสมัครสมาชิก

### ฝั่งผู้ดูแลระบบ (`useradmin`)
- เข้าใช้งานได้ที่ `http://localhost:3000/admin`
- บัญชีเริ่มต้น:
  - **Username:** `useradmin`
  - **Password:** `admin1234`
- ความสามารถในหลังบ้าน:
  - **จัดการนิยาย**: เพิ่ม/แก้ไข/ลบนิยาย อัปโหลดรูปปกจากเครื่อง ใส่ URL หรือเลือกปกสำเร็จรูป ปักหมุดนิยายแนะนำ และตั้งสถานะเผยแพร่/ฉบับร่าง
  - **ลงตอน / แก้ไขตอน**: เพิ่มตอนใหม่ แก้ไขเนื้อหาตอนเดิม นับจำนวนตัวอักษรแบบเรียลไทม์
  - **จัดการหมวดหมู่**: เพิ่ม แก้ไข ลบ และจัดลำดับหมวดหมู่
  - **ตั้งค่าหน้าเว็บไซต์**: แก้ไขชื่อเว็บ สโลแกน แถบประกาศ ข้อความ Hero หน้าแรก สีธีมหลักของเว็บ ข้อมูลติดต่อ และข้อความท้ายเว็บ
  - **บัญชี `useradmin`**: เปลี่ยนชื่อที่แสดงและเปลี่ยนรหัสผ่านได้อย่างปลอดภัย

## วิธีเริ่มต้นใช้งาน

ใช้ Node.js v22.5+ (ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม ฐานข้อมูลใช้ SQLite ในตัวที่ `data/novels.db`)

```bash
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่:
- หน้าเว็บอ่านนิยาย: `http://127.0.0.1:3000`
- หน้าหลังบ้าน (`useradmin`): `http://127.0.0.1:3000/admin`
